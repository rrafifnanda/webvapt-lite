# Security Policy

**Authorized testing only.** Gunakan webvapt-lite hanya pada sistem milikmu atau dengan izin tertulis. Jangan scan situs orang lain tanpa izin (melanggar hukum, termasuk UU ITE di Indonesia).

Jangan tambahkan: RCE / reverse shell, credential bruteforce, DoS/flood, WAF-evasion/stealth, exfiltrasi data. PR yang menambahkannya akan ditolak.

Lapor kerentanan tool ini via GitHub issue (jangan sertakan target ilegal).
